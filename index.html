Duo Bank Sync & Share Code

Changes sync live between everyone in the same room. Share Codes are only needed to move old progress in (for example from your original offline copy) or to keep a backup.

Duo Room Code

Enter the same room code as your duo partner and you will share one bank. Anyone with a different code sees a different bank. Treat the code like a password: anyone who has it can edit your bank.

Reset All Duo Gear Progress?
